CROSS-BROWSER EXTENSION INSTALLATION Choose your browser instructions below
🧭
Direct Extension Management URL:
chrome://extensions

Note: Browsers intentionally restrict web pages from launching chrome:// URLs directly for security. Please copy and paste chrome://extensions (or edge://extensions in Microsoft Edge, brave://extensions in Brave) into your browser address bar.

01
Extract Extension ZIP

Download nomalice-extension-browser.zip and extract to a local folder, or use the extension/ folder directly from the repository.

02
Open Extensions & Enable Developer Mode

Paste chrome://extensions into your address bar and switch on the Developer mode toggle switch at the top right.

03
Load Unpacked

Click the Load unpacked button and select the extracted extension folder (the directory containing manifest.json).

🦊
Firefox Add-ons & Debugging URLs:
about:debugging
about:addons

Note: Like Chromium, Firefox prevents web pages from opening internal about: URLs. Copy and paste about:debugging into your address bar.

01
Extract Extension ZIP

Download nomalice-extension-browser.zip and unpack it to any folder, or use the local extension/ folder.

02
Open Debugging Page

Paste about:debugging in the address bar and click This Firefox on the left panel.

03
Load Temporary Add-on

Click Load Temporary Add-on... and choose manifest.json from the extension folder.

Safari Web Extension Requirement

Unlike Chromium and Firefox, Safari does not load raw extension ZIPs directly from browser settings. Apple requires packaging Manifest V3 extensions into an Xcode container app on macOS before enabling them in Safari.

01
Download Safari Prep ZIP

Download nomalice-extension-safari.zip which includes the full extension plus safari-prep/.

02
Generate Xcode Project

On macOS, run: xcrun safari-web-extension-packager . --app-name "NoMalice AI"

03
Enable in Safari Settings

In Safari, check Allow Unsigned Extensions under Develop menu, run in Xcode, and toggle on in Safari > Settings > Extensions.
